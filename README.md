# 📸 Smart Passport Photo Studio (স্মার্ট পাসপোর্ট ফটো স্টুডিও)

**Smart Passport Photo Studio** হলো একটি আধুনিক ডেস্কটপ অ্যাপ্লিকেশন। এর মাধ্যমে মাত্র কয়েক ক্লিকে যেকোনো সাধারণ ছবিকে প্রফেশনাল পাসপোর্ট সাইজ ছবিতে রূপান্তর করা যায় এবং সরাসরি A4 পেপারে প্রিন্ট করা যায়।

## ✨ মূল ফিচারসমূহ (Key Features)

* **🤖 এআই ব্যাকগ্রাউন্ড রিমুভাল:** `rembg` (u2net_human_seg) ব্যবহার করে নিখুঁতভাবে ছবির ব্যাকগ্রাউন্ড মুছে ফেলা।
* **🎨 কাস্টম ব্যাকগ্রাউন্ড কালার:** কালার পিকার বা Hex কোড ব্যবহার করে পাসপোর্ট ছবির ব্যাকগ্রাউন্ড কালার পরিবর্তন।
* **🎛️ স্মার্ট এনহ্যান্সমেন্ট (Slider):** ছবির শার্পনেস এবং কন্ট্রাস্ট লেভেল (০-১০) নিয়ন্ত্রণ করার সুবিধা।
* **📄 অটোমেটিক A4 লেআউট:** এক ক্লিকে ১ থেকে ৩০ কপি ছবি দিয়ে স্বয়ংক্রিয়ভাবে A4 পেপার সাজানো।
* **🖨️ ডিরেক্ট প্রিন্ট সাপোর্ট:** অ্যাপ্লিকেশন থেকেই সরাসরি উইন্ডোজ প্রিন্টারের মাধ্যমে ছবি প্রিন্ট করার সুবিধা।
* **💾 সেভ অপশন:** প্রিন্টের জন্য সাজানো A4 শিট PDF বা JPG ফরম্যাটে সেভ করার সুবিধা।
* **💻 মডার্ন ইউজার ইন্টারফেস:** PySide6 দিয়ে তৈরি সুন্দর, ছিমছাম এবং ইউজার-ফ্রেন্ডলি ডিজাইন।
* **⚡ 1-Click Setup:** কোনো ধরনের কোডিং নলেজ ছাড়াই `.bat` ফাইলের মাধ্যমে অটোমেটিক পাইথন ও লাইব্রেরি ইন্সটল করার সুবিধা।

## 🛠️ টেকনোলজি (Technologies Used)

* **Language:** Python 3.x
* **GUI Framework:** PySide6 (Qt for Python)
* **Image Processing:** Pillow (PIL)
* **AI Background Removal:** rembg
* **Printing Support:** PySide6.QtPrintSupport

## 🚀 ইনস্টলেশন (Installation)

প্রজেক্টটি নিজের পিসিতে রান করার জন্য দুটি উপায় আছে:

### ⚡ উপায় ১: 1-Click Setup (সবচেয়ে সহজ - সাধারণ ইউজারদের জন্য)
আপনার পিসিতে পাইথন না থাকলেও কোনো সমস্যা নেই!
1. প্রজেক্টটি জিপ (ZIP) ফাইল হিসেবে ডাউনলোড করে আনজিপ করুন অথবা ক্লোন করুন।
2. ফোল্ডারের ভেতর থাকা **`Run_App.bat`** ফাইলে ডাবল ক্লিক করুন।
3. এটি স্বয়ংক্রিয়ভাবে পাইথন ও প্রয়োজনীয় সবকিছু ইন্সটল করে অ্যাপটি চালু করে দেবে।

### 💻 উপায় ২: ম্যানুয়াল সেটআপ (ডেভেলপারদের জন্য)
**১. রিপোজিটরি ক্লোন করুন:**
```bash
git clone [https://github.com/rjsheesh/Passport-photoMaker](https://github.com/rjsheesh/Passport-photoMaker)
```

**২. প্রয়োজনীয় লাইব্রেরি ইনস্টল করুন:**
```bash
pip install PySide6 Pillow rembg
```
*(নোট: প্রথমবার রান করার সময় rembg মডেলটি (u2net_human_seg) অটোমেটিক ডাউনলোড হবে, তাই ইন্টারনেট কানেকশন প্রয়োজন হতে পারে।)*

**৩. অ্যাপটি রান করুন:**
```bash
python passport_maker_v3.3.py
```

## 💡 কীভাবে ব্যবহার করবেন? (How to Use)

* **ছবি আপলোড:** "১. ছবি নির্বাচন" বাটনে ক্লিক করে আপনার ছবি আপলোড করুন। এআই স্বয়ংক্রিয়ভাবে ব্যাকগ্রাউন্ড মুছে ফেলবে।
* **কালার পরিবর্তন:** "২. ব্যাকগ্রাউন্ড কালার" সেকশন থেকে কালার পিকার দিয়ে বা হেক্স কোড লিখে পছন্দমতো কালার দিন।
* **ছবি ক্লিয়ার করুন:** স্লাইডার টেনে ছবির শার্পনেস এবং কন্ট্রাস্ট অ্যাডজাস্ট করুন।
* **কপি সিলেক্ট ও A4 লেআউট:** কত কপি ছবি লাগবে তা নির্বাচন করে "৫. A4 পেপার সাজান" বাটনে ক্লিক করুন।
* **সেভ বা প্রিন্ট:** সবশেষে "সেভ করুন" অথবা "প্রিন্ট করুন" বাটনে ক্লিক করে আপনার কাজ সম্পন্ন করুন।
